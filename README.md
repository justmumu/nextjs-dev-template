# Next.js Development Template

A planned JavaScript/TypeScript-only Next.js development template, carrying the development
rules of [python-dev-template](https://github.com/justmumu/python-dev-template)
into a general-purpose App Router project without business logic. Its generator,
guard, hooks, documentation and release tools will use the Node.js ecosystem.

This repository currently contains planning artifacts and Compound Engineering
configuration. The generator, application, Git hooks and protected-files guard
are not implemented yet.

The [implementation plan](.compound-engineering/artifacts/plans/2026-10-16-1751-feat-nextjs-development-template-plan.md)
defines the requirements, architecture, 16 implementation units and verification
criteria for the JavaScript-only toolchain.
Contributor and agent policy lives in [AGENTS.md](AGENTS.md).

Both Claude Code and Codex enable the same Compound Engineering plugin and team
preferences as the Python template. Trust and restart the relevant host to load
project settings. The local `compound-packs` directory is initially empty; its
no-packs warning is expected. Private research is excluded from Git.
